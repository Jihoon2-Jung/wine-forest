## 1. 기술 스택 및 Public 저장소 보안 규칙

### 1.1 기술 스택 (고정)
* **Frontend:** React 19 + TypeScript (`strict: true`) + Vite 6
* **Styling:** Tailwind CSS (CSS Variables 기반 Light/Dark 시맨틱 토큰)
* **Routing:** `react-router-dom` — **`HashRouter` 필수** (GitHub Pages 새로고침 시 404 오류 방지)
* **State Management:** Zustand (전역 DB 상태, 필터, 프라이버시 모드, 테마, 동기화 상태)
* **Local Cache:** `idb` (IndexedDB 래퍼 — `wine_db.json` 오프라인 캐시 및 2차 라벨 이미지 캐싱 대비)
* **PWA:** `vite-plugin-pwa` (Workbox 정적 에셋 프리캐싱, iOS/Android 홈 화면 추가 시 Standalone 앱 동작)
* **Icons & Charts:** `lucide-react` (아이콘), `recharts` (통계 차트)
* **Validation:** `zod` (JSON 스키마 런타임 검증 — Import 및 Drive Load 시 데이터 손상 차단)
* **Testing:** `vitest` + `@testing-library/react`
* **Migration Script:** Python 3.11+ (`openpyxl`)

### 1.2 Public 저장소 보안 절대 규칙 (CRITICAL)
1. **개인 데이터 커밋 절대 금지:** `wine-forest`는 Public 저장소입니다. 실제 와인 목록, 개인 메모, 엑셀 원본(`*.xlsx`), 변환된 DB(`wine_db*.json`), 검수 리포트(`migration_review*.md`)는 절대 저장소에 포함하지 않습니다. `.gitignore`에 반드시 차단 규칙을 명시합니다.
2. **환경변수 주입:** Google OAuth Client ID는 소스 코드에 하드코딩하지 않고 `import.meta.env.VITE_GOOGLE_CLIENT_ID`로만 읽습니다. (배포 시 GitHub Actions Secrets `VITE_GOOGLE_CLIENT_ID` 주입, 로컬은 `.env.local` 사용)
3. **최소 권한 준수:** Google OAuth Scope는 `https://www.googleapis.com/auth/drive.file`만 요청합니다. (`drive` 전체 권한 사용 금지)
4. **Client Secret 미사용:** 정적 SPA이므로 OAuth Client Secret을 코드나 환경변수에 포함하지 않습니다.

## 2. 프론트엔드 디자인 시스템 & 유명 와인 앱 UI/UX 벤치마크

### 2.3 타이포그래피 & 마이크로 인터랙션
* **폰트:** `Pretendard` 웹폰트(CDN) + 시스템 산세리프 폴백.
* **숫자 정렬:** 모든 가격, 병 수, 빈티지, 정원 수치에는 반드시 `font-variant-numeric: tabular-nums` 적용.

### 2.4 글로벌 프라이버시 모드 (`👁️` 가격 숨김 토글)
* **컴포넌트 강제 규칙:** 앱 내 모든 금액·외화·비고 출력은 반드시 공통 `<PriceText value={number} />`, `<FxNoteText />`, `<MemoText />` 컴포넌트를 사용합니다.
* **동작:** 상단 헤더의 눈 아이콘(`👁️` / `🙈`)을 1탭하면 전역 `isPrivacyMode`가 토글됩니다.
* **마스킹 범위:** 개별 병 구매가, 직구 외화 메모(`fxNote`), **비고/메모 원문(`memo` — 가격 텍스트 유출 0% 차단)**, 그룹 카드 평균가/범위, 보유 총액, 소비 총액, 선물 총액, `23.02.18 이후 누적 지출액`, 통계 차트의 금액 축·툴팁 및 **가격대별 보유 분포 차트 전체 오버레이**까지 **예외 없이 마스킹**합니다. (병 수·비율·빈티지·위치는 정상 표시)

## 3. 화면별 상세 기능 명세 (1차 MVP)

### 3.1 글로벌 내비게이션 쉘 (`AppShell`)
* **상단 고정 헤더 (`TopHeader`):**
  * 좌측: `JH Wine Forest` 심볼 + 타이틀 (모바일은 간결한 심볼/타이틀)
  * 우측 액션 아이콘 4개:
    1. **동기화 상태 배지 (`SyncBadge`):** 녹색(동기화됨) / 회색(오프라인 캐시) / 회전(저장중) / 주황(재인증·충돌 필요) — 탭 시 즉시 동기화 또는 재인증
    2. **프라이버시 토글 (`👁️`)**
    3. **테마 토글 (`☀️` / `🌙`)**
    4. **설정 (`⚙️`)**
* **하단 내비게이션 (`BottomNav`, 모바일) / 좌측 사이드바 (`DesktopSidebar`, PC):**
  1. **목록** (`Wine` 아이콘 — 기본 홈 `/`)
  2. **셀러** (`Grid3x3` 아이콘 — `/cellar`)
  3. **이력** (`History` 아이콘 — `/history`)
  4. **통계** (`BarChart3` 아이콘 — `/stats`)
* **플로팅 액션 버튼 (`+` FAB):** 목록·셀러 화면 우측 하단에 배치, 탭 시 **`QuickAddModal`(초고속 입고)** 즉시 오픈.

### 3.2 탭 1: 와인 목록 & 검색 (`InventoryPage` — 기본 첫 화면)
1. **요약 스트립:** 현재 필터링된 결과 요약 (`표시 중 267병 · 184종` | 총액 `<PriceText/>`).
2. **초고속 검색바:** 입력 즉시 클라이언트 메모리(`useDeferredValue`)에서 필터링. 검색 대상: `와인명`, `생산자`, `국가`, `지역`, `세부지역`, `빈티지`, `구매처`, `보관 위치`, `메모`. *(예: `부르고뉴` 검색 시 하위 `에세죠`·`볼네`·`샤블리` 등 모든 마을/밭/그랑크뤼가 함께 노출)*
3. **다중 필터 바:**
   * **색상 칩:** `전체 | R | W | SP | SW | RO` (다중 선택 가능)
   * **3단계 생산지 필터 (`국가` → `지역` → `세부지역`):**
     * 1단계 `국가` 선택 (예: `프랑스`, `이탈리아`, `미국`, `독일`, `칠레`)
     * 2단계 `지역` 선택 (예: `부르고뉴`, `보르도`, `상파뉴`, `토스카나`, `피에몬테`, `나파` — 선택 시 하위 모든 세부지역 와인이 함께 조회됨; `Vin de France` 등은 `프랑스`로 종결)
     * 3단계 `세부지역` 선택 (예: `에세죠`, `생줄리앙`, `뽀이약`, `볼게리`, `몬탈치노`, `오크빌` — 지역 선택 시 하위 세부지역 퀵 칩 자동 전개)
   * **보관 위치 필터:** `전체 | 삼성 | LG | 냉장고 신선 | 거실 | 미지정` *(생산지역과 용어 혼동 방지를 위해 '구역' 대신 '보관 위치'로 명시)*
   * **정렬:** `최근 구입순(기본) | 빈티지 오름차순(오래된 순, NV 맨 뒤) | 빈티지 내림차순 | 가격 높은순 | 가격 낮은순 | 보유 수량순 | 가나다순`
4. **와인 그룹 카드 (`WineGroupCard`):**
   * 그룹핑 키: **`wineId`** (`와인명 + 빈티지 + 용량 + 색상` 단위). 보유(`IN_STOCK`) 병이 1병 이상인 항목 표시 (토글로 `품절/소비완료 포함` 조회 가능).
   * **접힌 상태 정보:**
     * 좌측: `<WineThumbnail />` (2차 라벨 사진 존재 시 이미지, 1차는 와인 색상별 세련된 미니멀 보틀 플레이스홀더)
     * 상단: 색상 도트/칩 + **와인명** + 용량 배지(`750ml` 외 `250ml`, `375ml`, `1500ml` 등일 때만 표시)
     * 중단: **빈티지**(`2019` / `NV`) · `국가 · 지역 · 세부지역` (상위에서 끝나면 중복 없이 생략)
     * 하단: 보관 위치 요약(예: `삼성 1-3` 또는 `삼성 1-3 외 1곳`) · 가격(단가가 다르면 모바일은 `평균 ₩XX,XXX`, 데스크톱은 `평균 ₩XX,XXX` + `최저~최고` 범위 보조 표기, `<PriceText/>`)
     * 우측 강조 배지: **`×N`** (보유 병 수) + 빠른 소비 버튼(`🍷`)
   * **펼침 / 상세 바텀시트 (`WineDetailSheet`):**
     * 와인 마스터 정보 편집 버튼(와인명·생산자·국가·지역·세부지역·색상·빈티지·용량 일괄 수정; 수정 결과 기존 마스터와 `(와인명, 빈티지, 용량, 색상)` 4중 키가 겹치면 확인 후 기존 마스터로 안전 병합)
     * **`[+ 같은 와인 추가 입고]`** 버튼 (기존 마스터 정보가 자동 채워진 상태로 `QuickAddModal` 오픈)
     * **개별 병 리스트 (`BottleRow[]`):** 보유 중인 $N$병을 각각 행으로 표시:
       * `보관 위치 배지` | `구입일` | `구매처` | `개별 구매가(<PriceText/>)` | `외화(<FxNoteText/>)/비고(<MemoText/>)`
       * 행 우측 원클릭 액션: `[🍷 소비/선물]` `[📍 위치 이동]` `[✏️ 수정]` `[🗑️ 삭제]` *(마지막 남은 병을 완전 삭제해 보유 0병·이력 0건이 되면 고아 `WineMaster`를 자동 정리)*
     * 해당 와인의 과거 소비/선물 이력이 있으면 하단에 접힌 섹션(`과거 소비 이력 M병`)으로 함께 조회 가능.

### 3.3 초고속 와인 입고 모달 (`QuickAddModal`)
* **설계 목표:** 와인샵에서 방금 산 와인을 **15초 이내**에 등록. (모달이 열려 있는 동안 백그라운드 동기화로 `db` 참조가 갱신되어도 입력 중인 폼이 초기화되지 않도록 `useRef`로 초기 진입 시점만 세팅)
* **입력 필드 구성 (1화면 스크롤 최소화):**
  1. **와인명 (필수):** 입력 시 기존 `wines[]`에서 실시간 자동완성 제안. 기존 와인 선택 시 색상·국가·지역·세부지역·용량·빈티지 자동 채움 후 **빈티지 입력칸을 골드 하이라이트·포커스**해 새 빈티지 구매 시 오입력 방지.
  2. **빈티지 (필수):** 숫자 4자리 입력 + 우측 `[NV]` 원클릭 버튼.
  3. **색상 (필수):** 5종 컬러 세그먼트 버튼 (`R | W | SP | SW | RO`).
  4. **3단계 산지 — 국가 · 지역 · 세부지역(선택):** 3단계 자동완성 콤보박스 (국가·지역 필수, 세부지역은 마을/밭/그랑크뤼가 있을 때만 입력하고 상위 단계에서 끝나면 공란 유지).
  5. **수량 & 병당 가격 (필수):**
     * 수량: `[-] 1 [+]` 스텝퍼 (예: `6` 입력 시 `bottles[]`에 6개 개별 레코드 일괄 생성)
     * 가격: 원화 숫자 입력 + 빠른 가산 칩 (`+1만`, `+5만`, `+10만`)
  6. **보관 위치 (필수):** 구역별 그룹 드롭다운/피커 (각 선반 옆에 현재 잔여 공간 표시, 예: `삼성 1-2 (여유 3)` / `LG 2-1 (초과 -1)`).
  7. **구입일 & 구매처:** 구입일(기본 `오늘`), 구매처(최근 자주 쓴 구매처 상위 5개 칩 원클릭 선택 + 직접 입력).
  8. **선택 항목 (접힘 아코디언 `추가 정보`):**
     * 용량(기본 `750ml`, 빠른 선택 `375ml` / `750ml` / `1500ml`)
     * 생산자(`producer`), 외화/직구 메모(`fxNote`), 비고(`memo`)
     * `23.02.18 이후 집계 포함` 체크박스 (구입일이 `2023-02-18` 이상이면 자동 `true`, 미만이면 `false`, 수동 변경 가능)

### 3.4 초고속 소비 / 선물 모달 (`QuickConsumeModal`)
* 와인 카드의 빠른 `🍷` 버튼이나 개별 병 행에서 진입.
* **병 선택 (동일 와인 다수량일 때):** 보관 위치·구매가별로 1탭 라디오 선택 (1병뿐이면 자동 선택 생략).
* **출고 유형 토글:** `🍷 소비완료 (CONSUMED)` (기본) / `🎁 선물·양도 (GIFTED)`
* **날짜:** 기본 `오늘` (`YYYY-MM-DD`).
* **모임 / 대상 (`occasion`):** 한 줄 텍스트 입력 (예: `집들이`, `와인모임`, `지인 선물`).
* **간단 메모 (`memo`):** 선택 입력.
* **`[완료]`** 클릭 즉시 병 상태를 변경하고 `TastingRecord`를 생성한 뒤 로컬 반영 + Google Drive 동기화.

### 3.5 탭 2: 셀러 배치도 (`CellarMapPage`)
* **상단 셀러 요약 바:** 전체 보유 병수 / 총 정원 및 보관처 세그먼트 탭 — 항상 **`전체 보기 | 삼성 | LG | 냉장고 신선 | 거실`** 물리적 우선 순서로 배치.
* **물리적 수직 캐비닛 랙 뷰 (아래 `1-1` → 위 적층):**
  * 실제 셀러 구조 그대로 **바닥(`1-1`)에서 위(`1-2 → ... → 1-7`, `2단 2-1 → 2-7`, `3단 3-1 → 3-2`)로 쌓아 올리는 수직 캐비닛 프레임**으로 시각화합니다.
  * 다단 셀러(`삼성` 1~2단, `LG` 1~3단)는 단 구분선(`2단 (2-x)` 등)을 표시해 직관성을 높입니다.
  * 각 선반 행(`ShelfCard`): 선반 번호, `현재 병수 / 정원`, **InVintory 스타일 멀티 컬러 점유 바**, 상태 배지(`여유 +3` / `만석` / `초과 -2` 경고색).
* **선반 상세 드로어 (`ShelfDetailDrawer`):** 선반 클릭 시 해당 칸에 들어있는 모든 개별 병 목록 표시. 각 병에서 바로 `[🍷 소비/선물]` 또는 `[📍 다른 칸으로 이동]` 실행.
* **1탭 위치 이동 피커 (`MoveBottlePicker`):** 이동할 대상 선반을 `삼성 → LG → 냉장고 신선 → 거실` 순으로 여유칸과 함께 보여주고 1탭으로 즉시 이동 완료.
* **선반 설정 모달 (`ShelfConfigModal`):** 새 보관처/선반 추가, 이름·최대 정원 수정, 정렬 순서 변경 (`IN_STOCK` 병이 들어있는 선반은 삭제 방지, 삭제 시 과거 소비 이력의 `locationId`는 `null` 정리).

### 3.6 탭 3: 소비 · 선물 이력 (`HistoryPage`)
